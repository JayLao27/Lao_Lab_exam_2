# Food List App (Flutter + Firebase Firestore)

## Objective
A simple single-page Flutter app that performs **CRUD** (Create, Read, Update, Delete) operations on a food list stored in **Firebase Firestore**.

## Features
- **AppBar** with the title "Food List"
- **TextField** + **Add** button to add food
- **List** of foods that updates in real time
- **Edit** button (pencil icon) to rename a food
- **Delete** button (trash icon) to remove a food
- **Validation**: empty or blank input is rejected with a message

## Firebase Structure
```
foods (collection)
 └── <auto-generated id> (document)
      ├── name: string        e.g. "Adobo"
      └── createdAt: timestamp
```

## CRUD Explanation
| Operation | Function | Firestore call |
|-----------|----------|----------------|
| Create | `addFood()` | `foods.add({...})` |
| Read | `StreamBuilder` | `foods.orderBy('createdAt').snapshots()` (auto-updates) |
| Update | `editFood()` | `foods.doc(id).update({...})` |
| Delete | `deleteFood()` | `foods.doc(id).delete()` |

## Setup
1. Create a project in the [Firebase Console](https://console.firebase.google.com) and enable **Cloud Firestore** (test mode).
2. Install the FlutterFire CLI and link the project:
   ```
   dart pub global activate flutterfire_cli
   firebase login
   flutterfire configure
   ```
   This generates `lib/firebase_options.dart`.
3. Run the app:
   ```
   flutter pub get
   flutter run
   ```
